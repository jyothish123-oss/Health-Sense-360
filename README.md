# 🏥 Health Sense 360

### AI-Powered Chronic Disease Risk Prediction & Wellness Recommendation System

Health Sense 360 is a Machine Learning-powered healthcare analytics platform that predicts diabetes risk and provides personalized wellness recommendations through an interactive Streamlit dashboard.

The system combines predictive analytics, health monitoring, lifestyle guidance, and data visualization to help users make informed health decisions and promote preventive healthcare.

---

## 🚀 Features

- 🔍 Diabetes Risk Prediction using Random Forest Classifier
- 📊 Personal Health Dashboard
- ⚖️ BMI Calculation & Health Status Analysis
- 💧 Daily Water Intake Recommendation
- 🔥 Daily Calorie Requirement Estimation
- 🌟 Wellness Score Generation
- 📈 Interactive Health Risk Visualizations
- 🍽 Personalized Diet Recommendations
- 🏃 Customized Exercise Plans
- 📜 Prediction History Tracking
- ⬇ Downloadable Health Reports

---

## 🧠 Machine Learning Pipeline

### Data Preprocessing
- Data Cleaning
- Feature Scaling using StandardScaler
- Train-Test Split Validation

### Model
- Random Forest Classifier

### Input Features
- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

### Output
- Diabetes Risk Prediction
- Risk Probability Percentage
- Wellness Score
- Personalized Health Recommendations

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Health-Sense-360.git
```

### Navigate to Project Folder

```bash
cd Health-Sense-360
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
